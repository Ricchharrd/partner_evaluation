# 해외 건설 파트너사 보고서 작성 기준

기본 산출물은 아래 5개 항목의 한국어 보고서 초안이다. 요약만 작성하고 종료하지 않는다.
사용자가 회사 양식을 제공했다면 같은 근거를 그 양식에 맞춘다. 아래는 공인된 회사 양식이 아니라 기본 구성이다.

## 1. 기업개요
법인명, 국가, 사업·역할, 대표 실적, 주요 주주·지배구조를 근거 범위에서 쓴다.
같은 그룹·컨소시엄·유사 이름의 다른 법인을 혼동하지 않는다. 미확인은 그대로 남긴다.

## 2. 재무 검토
제공된 최근 3개년 중 확보된 연도만 비교한다. 매출·영업이익·순이익·자산·부채·자본·차입금·영업CF를 요약한다.
계산된 비율과 잠정 점수를 재사용한다. 추출값을 임의 수정하거나 단위배수를 다시 곱하지 않는다.
원문 근거, 통화, 연결/별도, 기간, 오류·누락·대용치를 표시한다. 순차입금과 총금융부채를 바꾸어 쓰지 않는다.
기간이나 기준이 다르면 성장·추세를 단정하지 않는다. 현금흐름·운전자본과 프로젝트 수행 여력을 연결할 때는 해석임을 밝힌다.

## 3. 공개 현안 및 사업역량
중요한 현안 최대 5개에 대해 사실, 발표일/사건일, 해당 법인과의 관련성, 출처, 사업상 의미를 쓴다.
수주·협약·착공·준공과 EPC/시공/개발/컨소시엄 역할을 구분한다.
안전·분쟁·지연·제재가 검색되지 않았다고 없다고 쓰지 않는다. 제외 처리된 기사는 결론의 근거로 사용하지 않는다.

## 4. 종합 검토
확인된 강점, 주의할 위험, 판단 한계를 재무와 기사 근거에 연결한다.
공개자료만으로 실제 동원 가능 자금이나 프로젝트 수행 적합성을 확정하지 않는다.
비공개 자료·내부 의견을 결합했다면 내부 근거와 공개 근거를 구분한다.
재무 오류가 있으면 그 수치의 결론만 보류하고 다른 확인 가능한 부분은 작성한다.

## 5. 추가 확인사항과 다음 조치
담당자가 해야 할 중요한 조치 최대 3개를 질문/필요 자료/이유 형태로 묶는다.
예: 미공개 차입 만기표 요청, 특정 프로젝트 실제 수행 범위 확인, 상충 재무계정 원문 확인.
일반적인 항목 전체를 다시 입력시키지 않는다. 이미 확인한 대상·범위를 반복 질문하지 않는다.
최종 승인 상태는 미승인으로 두고 사용자 실제 결정이 있을 때만 바꾼다.

## 파일과 처리 범위
보고서 본문을 먼저 완성한다. 환경에 Word 생성 도구가 허용되면 DOCX를 만들고 페이지를 검토한다.
도구가 없으면 완성된 Markdown/본문을 제공하고 DOCX를 생성하지 못했다고 명시한다.
사용자가 자료 한 건의 검토를 요청한 것은 그 범위의 초안 작성을 허용한 것이며, 별도 '보고서 작성 승인'을 반복 요구하지 않는다.
대량 원문 재처리·새 외부 검색·재시도·자료 범위 확대는 기존 비용·보안 승인의 범위를 확인한다.
